# Voicify

A local text-to-speech agent for long-form narration, built on Kokoro-82M. Runs entirely
on your machine; no text is sent anywhere.

Status: early development. See [docs/phases.md](docs/phases.md) for the build plan.
The full README (installation, voices, CLI and API examples, troubleshooting) is written in Phase 9.

## Quick setup

```bash
uv sync
```
